# WinUI Samples Browser

This folder contains the combined WinUI 3 samples browser application.

## Structure

```
SamplesBrowser/
├── App.xaml / App.xaml.cs          – Application entry point
├── MainWindow.xaml / .xaml.cs      – Main window with NavigationView sidebar
├── Pages/
│   ├── HomePage.xaml               – Home / welcome page
│   ├── SampleHostPage.xaml         – Generic host page for sample UserControls
│   └── <group>/<component>/<sample>/  ← auto-populated by ingest-samples.ps1
│       └── Sample.xaml / .xaml.cs
├── Services/
│   └── TocService.cs               – Loads and models toc.json
├── Assets/
│   └── toc.json                    ← auto-generated by ingest-samples.ps1
└── SampleRegistry.cs               ← auto-generated by ingest-samples.ps1
```

## Running the Browser

Before opening in Visual Studio, run the ingest script to populate samples:

```powershell
cd scripts
.\ingest-samples.ps1
```

Then open `SamplesBrowser.csproj` in Visual Studio 2022 and press F5.

## Requirements

- Visual Studio 2022 (17.8+)
- Windows App SDK 1.5+
- .NET 8
- Windows 10 version 1809 (build 17763) or later
